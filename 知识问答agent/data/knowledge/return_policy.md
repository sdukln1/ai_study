# 退货退款政策

## 退货条件
自签收之日起 7 天内，商品未使用且不影响二次销售的，可以申请无理由退货。定制类商品、生鲜食品、贴身衣物不支持无理由退货。

## 退货流程
1. 在 App 中进入"我的订单"，选择需要退货的订单，点击"申请售后"。
2. 选择退货原因，提交申请，等待审核（一般 24 小时内完成）。
3. 审核通过后，系统会发送退货地址，请按地址寄回商品并填写物流单号。
4. 仓库验收合格后，退款将在 1-3 个工作日内原路退回。

## 退款说明
- 原路退回：支付宝、微信支付一般 1-3 个工作日到账，银行卡 3-7 个工作日到账。
- 使用优惠券购买的订单，退款金额为实际支付金额，优惠券在有效期内会自动退回。
- 运费说明：质量问题退货由商家承担运费；无理由退货运费由买家自理（运费险除外）。

## 常见问题
问：超过 7 天还能退货吗？
答：如商品存在质量问题，签收后 15 天内仍可申请质量问题退货，需提供照片或视频凭证。
